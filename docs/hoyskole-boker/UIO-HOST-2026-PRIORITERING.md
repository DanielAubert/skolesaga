# UiO høsten 2026 — oversikt og prioritert rekkefølge

Målt 2. august 2026, etter at eksamensarkivet ble sortert i
institusjonsmapper. Erstatter den foreløpige rangeringen fra tidligere samme
dag, som bygget på skjelettlista alene og derfor overså emner uten skjelett.

**Grunnlaget er tre ting, alle etterprøvbare:**

| kriterium | kilde | hvorfor |
|---|---|---|
| **Obligatorisk i program** | UiOs egne programsider | et obligatorisk emne tas av HELE kullet, hvert år |
| **Undervises høst 2026** | UiOs emnesider | hard filtrering — sjekket emne for emne |
| **Arkivdybde (terminer)** | `TERMINER.csv` | avgjør om vi KAN skrive en kalibrert bok |

⚠ **Studenttall finnes ikke.** UiOs emnesider oppgir dem ikke, og DBHs API ga
ikke riktig tabell på rimelig antall forsøk. Rangeringen hviler derfor på
obligatorisk-i-program, som etter vår vurdering er et sterkere signal uansett.

## Metode — slik listen kan gjenskapes

```bash
# arkivdybde per UiO-emne
#   ~/Desktop/Eksamner/UiO/<EMNEKODE>/          filtelling
#   ~/Desktop/Eksamner/_nedlastet-2026-07-30/TERMINER.csv   terminer

# undervisningssemester (emne for emne, UiOs egne sider)
#   https://www.uio.no/studier/emner/<fak>/<institutt>/<EMNEKODE>/
#   ⚠ engelskspråklige emner skriver «Teaching»/«Autumn», ikke
#     «Undervisning»/«Høst» — et søk på bare norsk gir falske «uavklart»
```

⚠ Fakultetsstien må gjettes fra emnekoden; UiO har ingen oppslags-URL på
emnekode alene, og emnesøket er en JS-app som ikke lar seg hente.
